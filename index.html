Cosmic Explorer

A single-page web application for exploring astronomy and space discovery data

Browse celestial objects from our solar system and beyond. Search, filter, and discover planets, moons, stars, and galaxies — powered by NASA's open APIs.

About the Project

Course

CSCI 3230U — Web Development (Winter 2026)

Type

React Single-Page Application (SPA)

Data Source

NASA Open APIs (APOD, NEO, Mars Rover, Earth imagery)

Status

M1 Static Prototype — Milestone 1 Complete

Core Features

Search & Filter

Find objects by name, filter by type (planet, moon, star, galaxy), and sort by distance, size, or name.

Detail Pages

Each object has a dedicated page with rich data: specs, exploration history, surface features, and more.

Favourites

Save favourite objects locally — persisted in localStorage, accessible across sessions.

Responsive & Accessible

Mobile-first design, WCAG AA contrast, semantic HTML, keyboard navigation, and screen-reader support.

Project Milestones

M0

Team & Topic

Team formed, GitHub repo created, topic locked: Cosmic Explorer using NASA APIs.

M1

Proposal & Static Prototype

Written proposal, wireframes, and static HTML/CSS prototype (this site) — semantic, responsive, accessible.

M2

React Foundation

Prototype rebuilt as React app with Vite: components, props, state, event handling, list rendering on mock data.

M3

Baseline Working Project

Live API integration, search/filter/sort, routed detail views, persisted favourites, controlled form, tests, deployed.

M4

Independent Concept & Video

Research & integrate a novel concept (e.g., TanStack Query, Framer Motion, PWA), produce a 1–3 min demo video.
