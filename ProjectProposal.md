## Web Dev Project: Cosmic Explorer Proposal

## Formal Pitch:

Cosmic Explorer is a web page designed to be its own online encyclopedia for astronomy. Our mission is to aid beginner astronomy majors or new astronomers to learning

Cosmic Explorer is an interactive educational platform designed to make learning about the universe engaging and visually appealing. The website will allow users to explore planets, stars, galaxies, black holes, and other celestial objects through organized information, interactive features and astronomy events. This website is designed for first-year astronomy students and enthusiasts, the platform will simplify complex scientific concepts while encouraging curiosity.

Our goal is to create an engaging digital experience that helps users better understand the universe and inspires a deeper interest in astronomy.

## [Define User Personas & Core User Flows](https://github.com/marjiimrym/WebDevCSCI-Group-Project/issues/2)

A user who is curious about space but does not have an astronomy background. They want to browse planets, stars, moons, and galaxies and learn basic information in an easy-to-understand format.

A student who wants to quickly find information about celestial objects for learning or school-related purposes. They may search for a specific object or compare basic properties such as distance, size, and object type.

Core User Flows

## 1. Casual Space Explorer

## 2. Student / Learner


- Explore objects: User opens the Explore page, browses available celestial objects, selects an object, views its information.

- Search: User enters the name of an object, applies the search, sees matching results.

- Filter: User selects an object type (planet, moon, star, galaxy, etc.), applies the filter, sees relevant objects.

- Sort: User chooses a sorting option such as size or distance, results are reordered.

- Learn about the website: User opens the About page, reads about the purpose of Cosmic Explorer.
