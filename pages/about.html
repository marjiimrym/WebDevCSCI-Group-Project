01The product

What is Cosmic Explorer?

Cosmic Explorer is a single-page web application for exploring astronomy and space discovery data.

Browse celestial objects from our solar system and beyond. Search, filter, and discover planets, moons, stars, galaxies, and nebulae — powered by NASA's open APIs.

  • Search & Filter

    Find anything

    Find objects by name, filter by type (planet, moon, star, galaxy, nebula), and sort by distance, size, or name.

  • Detail Pages

    Go deeper

    Each object has a dedicated page with rich data: specs, exploration history, surface features, and more.

  • Favourites

    Keep what you find

    Save favourite objects locally — persisted in localStorage, accessible across sessions.

  • Responsive & Accessible

    Built for everyone

    Mobile-first design, WCAG AA contrast, semantic HTML, keyboard navigation, and screen-reader support.

02The reason

Why was it built?

Cosmic Explorer is the group project for CSCI 3230U — Web Development.

The course asks each team to design and build a single-page application that browses and acts on a collection of items drawn from a web service: a searchable, filterable collection of cards, each with a detail page, favourites, and data loaded from an API.

Our team applied that brief to astronomy. Planets, moons, stars and galaxies form the collection; NASA's public API platform is the data source. The work is delivered in five graded milestones, so the product grows from a static prototype into a deployed application.

03Data sources

Powered by NASA Open APIs.

The primary data source for Cosmic Explorer is NASA's public API platform at api.nasa.gov. Potential endpoints and datasets include:

  • 01

    APOD

    Astronomy Picture of the Day.

  • 02

    Near Earth Objects

    Near Earth Object Web Service.

  • 03

    Mars Rover Photos

    Imagery from NASA's Mars rovers.

  • 04

    Earth Imagery

    Earth imagery and related datasets.

The team will finalize the specific endpoints after evaluating available data for search, filtering, and detailed object views.
